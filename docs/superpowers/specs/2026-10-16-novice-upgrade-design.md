# StyleMuse 新手友好升级设计（方案C）

日期：2026-10-16
状态：已获用户批准（范围：全套 + 首页新手引导；不做虚拟试穿）

## 背景与目标

目标用户：完全不懂时尚的新手。评估结论：现有站点能"定方向"（档案→推荐→57/48/42 套可落地方案），但存在四个新手痛点：入口太重（须先填完整档案）、缺"今天怎么穿"的即时答案、缺基础术语扫盲、缺"用已有衣服穿好看"的能力。本次升级参考 Style DNA（快速测验出报告）、Acloset/Stylebook/Cladwell（胶囊衣橱与已有单品重组）、Dressika（场合速查）等市场产品的方法论。

## 功能范围

### 1. 新增页面 /beginner「新手学堂」（单页四区，顶部锚点导航）
- **风格测验**：10 题快问快答（单选），题目覆盖：场景偏好、颜色偏好（色卡）、轮廓偏好、气质自评、穿搭心理、妆容态度、发型偏好、鞋包偏好、穿衣方式、他人评价。每题答案映射若干风格权重；评分函数输出主风格 + 混搭方向 + 3 条推荐理由；结果卡展示风格图（SmartImage）与「查看风格详情 / 看对应穿搭方案」按钮。数据与逻辑放 `src/data/quiz.ts`（含 `runQuiz(answers)`）。
- **穿搭万能公式**：6 张公式卡：三色原则、上紧下松/上松下紧、腰线比例、同色系叠穿、胶囊衣橱 10 件套清单、场合速查表（通勤/约会/聚会/见长辈）。
- **新手雷区对照**：6 组 ❌→✅ 正反卡：配色灾难、显矮、显胖、堆砌过度、场合错配、盲目跟风。
- **时尚词典**：约 50 条可搜索术语，分类：趋势词 / 单品词 / 妆容词；每条含中文名、英文名、一句话解释、关联跳转（如有）。数据 `src/data/glossary.ts`，提供 `getGlossary(term)` 供内联解释复用。

### 2. 我的衣橱新增「胶囊衣橱」Tab
- `src/data/capsule.ts`：约 28 件常见单品（上装/下装/连衣裙/外套/鞋/包），每件 id、名称、emoji、类别、场景适配标签。
- 交互：勾选已有单品 → 实时显示覆盖率 → 选场合+季节 → 「生成今日穿搭」输出 3 套组合（上衣+下装+鞋包+一句搭配逻辑）→ 「查看完整方案」跳转 /outfits 并携带查询参数（?season=&scenario=），OutfitStudio 挂载时读取查询参数预填筛选；根据风格倾向给出「补购清单 Top3」。
- 勾选状态存入 AppStore 新字段 `closetItems: string[]`（IndexedDB 持久化）。

### 3. 生僻词内联解释
- 新组件 `src/components/GlossaryTip.tsx`：术语文本旁「?」小标，悬停/点击显示一句话解释。
- 接入点：潮流卡与详情弹窗的趋势名、方案弹窗高频生僻词。

### 4. 首页「新手快速开始」三步引导
- Hero 下方新增强调区：① 3 分钟风格测验（→/beginner）② 看我的专属推荐（→/results）③ 照着方案穿出门（→/outfits），沿用现有深色横幅风格。

### 5. 导航与路由
- NAV 增加「新手学堂」项；注册 `/beginner` 路由。

## 技术约束
- 全部本地运行、零外部依赖；复用现有设计系统（撞色主题 token 与组件类）。
- 新增字段向后兼容（closetItems 可选）。
- 保持隐私优先：勾选数据仅存本机。

## 验证
- 类型检查（tsc --noEmit）+ 生产构建（npm run build）。
- 浏览器实测：测验完整流程、衣橱生成 3 套组合、词典搜索、内联解释悬停、首页引导跳转。
